# LFPP

Code for the paper:

**LFPP: Long-Term Time Series Forecasting with Phase-Aligned Periodic Prior**

The paper is currently under review. The code, training scripts and configuration files will be released in this repository upon acceptance.

## Datasets

All datasets used in the paper are publicly available (ETT, Electricity, Traffic, Weather). Download and preprocessing instructions will be included with the release.
